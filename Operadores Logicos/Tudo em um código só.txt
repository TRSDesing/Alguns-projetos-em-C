Tudo em um código só

introdução:

#include <stdio.h>

"Corpo do código":

int main(){}

variáveis que já estão com o valor atribuído por causa do "=":

int a = 5;
int b = -10;
int c = 0;

Logica do "Se" e "senão":

Se "a" é maior que 0 e "b" é menor que 0 o "&&" vai verificar se ambos os números são positivos, o "||" vai verificar se pelo menos um numero é positivo e o "==" vai verificar se o "c" é igual a zero:

se (a > 0 && b < 0 || c == 0){
mostre("A condição é verdadeira. \n");
} senao {
mostre("A condição é falsa. \n");
}

Para fechar o código:

Return 0;

}
